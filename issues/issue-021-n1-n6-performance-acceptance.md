# [US-010] 建立 N1-N6 性能验收套件

## Description

建立覆盖吞吐、幂等、故障恢复、查询性能和 SSE 实时性的自动验收套件，并输出可审计报告。

## Acceptance Criteria

- [ ] 运行 50 个并发任务、合计 500 个采样点/秒且持续至少 10 分钟的负载。
- [ ] 对账确认合法指标零丢失。
- [ ] 注入 2% 重复批次后确认零重复落库。
- [ ] worker 强制退出并重启后确认数据完整且保持幂等。
- [ ] 8 小时历史曲线、约 28,800 原始点/key、`max_points=500` 的查询 P95 小于 200ms。
- [ ] 单任务全量摘要查询 P95 小于 100ms。
- [ ] 测试窗口内每条样本从落库到 SSE 客户端收到事件的延迟小于 1 秒。
- [ ] 输出包含 N1-N6 测量值、阈值和 PASS/FAIL 的机器可读报告。
